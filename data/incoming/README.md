# data/incoming/ — сюда пишем СЕБЕ (файл-первый)

Результаты с чужих территорий (ОК/VK) — только чтение. Всё, что добыто,
пишем **СЕБЕ**, в файлы этого репо. Экспорт картотеки из расширения
приземляется сюда.

## Экспорт картотеки (ОК)

1. В расширении на ok.ru — экспорт картотеки (карточек).
2. Положите файл в `data/incoming/` под именем по конвенции:

   ```
   YYYY-MM-DD__ok-kartoteka-export.json
   ```

   Например: `2026-08-21__ok-kartoteka-export.json`.

   Или запустите помощник (сам переименует, допишет в журнал и подскажет коммит):

   ```powershell
   pwsh scripts/Import-OkExport.ps1 -Path <путь-к-файлу-экспорта>
   ```

3. Закоммитьте:

   ```
   chore: картотека из расширения → data/incoming (файл-первый)
   ```

## Правила

- **append / только новые файлы** — добычу не переписываем задним числом.
- **provenance**: в имени файла — дата; в `reports/` при необходимости — откуда.
- Живые не публикуются; массового сбора нет; Иванову И.И. не терзать.
- Подкаталог `archive/` — для отработанных поступлений.
