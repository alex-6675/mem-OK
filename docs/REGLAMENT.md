## Применяемая  стилистика текстов.
Эвфемизмы: негативные ассоциации не транслируем (никаких могил
и катастроф и высосаных мозгов берез трубочку для котелей);
лёгкие метафоры приветствуются (скакалка — можно).
Юмор, ирония, сарказм - также.  


## Страховка от дурака
Инструмент трогают просто люди. Не существует писателя
инструкций, который объяснит «тупому» — значит, инструмент
страхует САМ:
1. верное действие — единственное или самое лёгкое;
2. необратимое — подтверждение человеческими словами
   (не терминами);
3. у каждого действия строка «ЗАЧЕМ» — одна человеческая
   фраза в интерфейсе;
4. дурак не ломает общую базу: его запись идёт в его incoming/,
   в общую — только через слияние с-админа (уже в архитектуре);
5. отмена — где возможна.
Где приглашён волонтёр — там страховка. Исключений нет.


## Регламент действий
1. Одно движение — один отчёт. Движения без отчёта нет.
2. Чужие территории (ОК/VK) — только чтение: наблюдение, подхват, ПКМ — чтение. Результаты пишем СЕБЕ: reports/, logs/activity/, data/incoming/.
3. Живое тело не трогаем: для VK — скальпель на слепке; живая маркировка на ОК — после подтверждения стабильности DOM.
