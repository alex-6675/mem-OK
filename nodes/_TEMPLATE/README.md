# _TEMPLATE — направление-независимый шаблон

Этот каталог — источник для создания экземпляров направлений.
**Не правится напрямую** — только копируется в новый узел.

```text
nodes/
├── _TEMPLATE/          ← шаблон (не трогать)
└── <направление>/       ← экземпляр направления (mem, и др.)
```

Создание нового экземпляра — одно движение через скрипт
`scripts/create-dev-repo.ps1` (подставляет роль и конфигурацию API ОК).
