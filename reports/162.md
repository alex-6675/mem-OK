Поясняю по файлу, блок за блоком. В консоли три события и две причины.

Блок 1: Build.ps1 — хорошо

=== Сборка завершена === Результат: …\mem-OK\dist
Артефакт готов, цепь сборки жива. Это не ошибка.

Блоки 2 и 4: . RunEdgeCdp.ps1 → «param is not recognized» — моя ошибка в базе

Причина техническая: в PowerShell param() обязан быть первой инструкцией файла (допускаются только комментарии и #Requires перед ним). В базе, которую я дал и которую Кодер вставил в 2d4d501, порядок такой:
```
#Requires -Version 7.0
Set-StrictMode -Version Latest      ← раньше param
$ErrorActionPreference = 'Stop'     ← раньше param
param( ... )                        ← строка 7 → «param is not recognized»
```
Парсер видит param как команду, а не как объявление параметров. Вина моя (база), Кодер не поймал. Dot-source (. 'путь') здесь ни при чём — файл сломан при любом запуске.

Блок 3: .\scripts\Run-user_01.ps1 → «not recognized» — файла нет

Это вторая дыра из ревизии: обёртки в коммите 2d4d501 декларированы сообщением, но не положены в репо. PowerShell честно говорит «не знаю такого». Ждать TASK-0162 (обёртки в нём).

Лечение (уже в TASK-0162; если ушло — дошлите дополнением одной строкой)

TASK-0162 доп.: в scripts/RunEdgeCdp.ps1 переставить param ПЕРВЫМ:
сразу после #Requires; Set-StrictMode и $ErrorActionPreference —
ПОСЛЕ param. Верный верх файла:
```
RunEdgeCdp.ps1 — чистый Edge c CDP для тестов ok.ru.
#Requires -Version 7.0
param(
    [ValidateSet("sadmin","admin","moderator","editor","user01")]
    [string]$Profile = "user_01"
)
Set-StrictMode -Version Latest
$ErrorActionPreference = 'Stop'
```
Как запускать после фикса
```
.\scripts\Run-user_01.ps1        # обёртка, Play в VS Code тоже
pwsh scripts\RunEdgeCdp.ps1 -Profile s_admin   # с ключом из pwsh
```
Dot-source не нужен вовсе.

Если не ждать Кодера (одно движение руками)

Открыть scripts/RunEdgeCdp.ps1, вырезать блок param(...) и вставить его сразу после строки #Requires -Version 7.0, а Set-StrictMode/$ErrorActionPreference опустить ниже. Сохранить — и .\scripts\RunEdgeCdp.ps1 поедет (профиль user_01, порт 9226). Обёртки появятся с TASK-0162.

Итог по файлу: сборка здорова, скрипт запуска сломан порядком param (моя вина, лечится перестановкой), обёртки отсутствуют (вина Кодера, в TASK-0162). Две дыры, два движения, одна квота.
